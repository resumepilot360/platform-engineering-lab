# ADR-0005: Kustomize for first-party manifests, Helm for third-party charts

- Status: Accepted (2026-10-28)

## Decision
- First-party manifests (namespaces, RBAC, policies, apps) use **Kustomize**, which is built into kubectl.
- Third-party software is installed from **pinned Helm charts** with values files in Git.
- Argo CD (Phase 4) renders both, so there is one tool per ownership type.
- Validation: `scripts/validate.sh` runs kubeconform in strict mode against
  Kubernetes 1.35 schemas plus the CRD catalog. A missing schema is an error, not a skip.

## Layout deviations from the proposed structure
- `tests/<phase>/`: acceptance scripts and the throwaway manifests they deploy,
  kept apart from platform config that Argo CD will own.
- `reports/`: acceptance logs, regenerated by the test scripts.
- `.tools/` (gitignored): repo-local, checksum-verified kubectl matching the cluster minor version.
